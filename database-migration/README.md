# Oracle to PostgreSQL Migration

## Overview

This project contains database migration examples and documentation for migrating database objects and SQL from Oracle to PostgreSQL.

## Migration Areas

* Oracle database schema
* Tables and columns
* SQL queries
* Stored procedures
* Functions
* Views
* Triggers
* Sequences
* Data migration
* PostgreSQL conversion
* Migration testing and validation

## Purpose

The purpose of this project is to maintain reusable examples and technical documentation for Oracle to PostgreSQL database migration and modernization.

## Security

Only sample, test, or non-confidential database information should be stored in this repository.

Do not upload passwords, connection strings, API keys, certificates, production credentials, or confidential client data.
